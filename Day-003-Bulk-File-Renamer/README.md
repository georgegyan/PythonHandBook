# Bulk File Renamer

A simple Python script to rename multiple files in a folder quickly and consistently.

## Features

- Rename files in bulk using a fixed prefix or a custom naming pattern
- Keeps file extensions unchanged
- Useful for organizing image, document, or downloaded file collections

## Usage

1. Open `bulk_renamer.py` in your Python editor.
2. Update the folder path and rename settings as needed.
3. Run the script:

```bash
python bulk_renamer.py
```

## Notes

- Always check the target folder contents before running the script.
- Keep a backup if you need to preserve original file names.

## Files

- `bulk_renamer.py` — main renaming script
- `images/` — example folder for sample files
